# Recipe Management App (React + Vite)

## Run the project
1. Extract this folder.
2. Open the `recipe-management-app` folder in VS Code.
3. Open Terminal in this folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the localhost URL printed by Vite.

## Included features
- Home page matching the cream and sage-green RecipeBook design
- Recipe list with search and category filter
- Add recipe form
- Favorites
- Recipe details, ingredients, instructions, and delete action
- localStorage persistence for recipes and favorites
- Responsive layout for mobile and desktop

Food photos use remote Unsplash image URLs, so internet access is needed for those images.
